Nome: DripLab



Descrição do Projeto: 
A DripLab é uma marca de streetwear digital-first voltada a pessoas que desejam se reinventar e expressar sua identidade por meio do estilo, mas enfrentam limitações financeiras. Seus criadores acreditam que vestir-se bem e identificar-se com o que se veste é um direito universal. Além da proximidade entre empresa e cliente ser considerada essencial para experiências interativas e personalizadas, nas quais o consumidor não apenas compra, mas se identifica com a marca e participa de seus projetos.



Objetivo do Projeto:
O projeto tem como objetivo criar uma plataforma digital que conecte moda, cultura urbana e tecnologia, proporcionando uma experiência de compra acessível, personalizada e interativa.



Funcionalidades:
Cadastro de usuários: criação de contas para novos clientes.

Login: autenticação dos usuários cadastrados.

Perfil do usuário: visualização e edição de informações pessoais.

Catálogo de produtos: exibição de peças de roupa e acessórios disponíveis.

Pesquisa de produtos: busca de produtos por seus nomes.

Página individual de produtos: apresentação de informações específicas de cada produto.

Carrinho de compras: adição e gerenciamento dos produtos selecionados.

Gerenciamento de endereços: cadastro e armazenamento de endereços de entrega.

Finalização de pedidos: registro das compras realizadas.

Acompanhamento de pedidos: consulta das informações e do status dos pedidos.

Página de parceria: formulário para pessoas interessadas em estabelecer parcerias com a marca.



Tecnologias Utilizadas:
Vscode, HTML5, CSS3, JavaScript, Node.js, Express, MySQL, Sequelize, JSON Web Token (JWT), Bcrypt, Git e GitHub
